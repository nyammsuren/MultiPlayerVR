# MultiPlayer VR

Олон хэрэглэгч нэг хоосон VR өрөөнд орж, микрофоноор хоорондоо ярилцах туршилт.
[RoomVR](https://github.com/nyammsuren/RoomVR)-тэй ижил three.js + WebXR суурьтай.

**Турших:** https://nyammsuren.github.io/MultiPlayerVR/

## Хэрхэн ажилладаг вэ

- **Сервергүй.** GitHub Pages дээр шууд ажиллана. Хэрэглэгчид [Trystero](https://github.com/dmotz/trystero)-гоор
  (нийтийн Nostr relay ашиглан) бие биеэ олоод, дараа нь **WebRTC**-ээр шууд (peer-to-peer) холбогдоно.
- **Дуу:** микрофоны урсгал хэрэглэгч бүрт шууд очно. Дуу нь 3D (орон зайн) — хүн хаана зогсож байгаагаас
  дуу нь сонсогдоно.
- **Аватар:** толгой, бие, нэр, VR-д гар. Ярьж байх үед нүүрний хаалт ногооноор гэрэлтэнэ.
- **Өрөө:** ижил өрөөний кодтой хүмүүс нэг өрөөнд орно. Код нь URL-д (`?room=...`) хадгалагдана.

## Турших (2 ба түүнээс олон хэрэглэгч)

1. Линкийг нээгээд нэрээ бичиж, **Өрөөнд орох** дарна. Микрофоны зөвшөөрөл өгнө.
2. **🔗 Холбоос** товчоор линкийг хуулж нөгөө хүндээ (эсвэл Quest шил рүү) явуулна.
3. Хоёулаа нэг өрөөнд орсны дараа бие биеэ харж, ярилцана.
4. VR шилэнд: **ENTER VR** товч.

> Нэг компьютер дээр 2 tab нээж туршвал echo гарна — чихэвч хэрэглэх эсвэл өөр төхөөрөмж ашиглаарай.

## Удирдлага

| | Компьютер | VR (Quest) |
|---|---|---|
| Хөдлөх | W A S D / сум | Зүүн жойстик |
| Эргэх | Хулганаар чирэх | Баруун жойстик (30°) |
| Микрофон | M эсвэл 🎤 товч | X товч |

## Файлууд

```
index.html      нэвтрэх цонх, HUD, importmap
js/main.js      scene, rig, удирдлага, байрлал илгээх
js/room.js      хоосон өрөө + оролцогчдын самбар
js/avatar.js    бусад хэрэглэгчийн аватар, 3D дуу
js/network.js   Trystero P2P холболт (pose, info, audio)
```

## Хязгаарлалт

- Mesh P2P тул нэг өрөөнд **~8 хүн** хүртэл тохиромжтой.
- Зарим байгууллагын/гар утасны сүлжээ WebRTC шууд холболтыг хаадаг. Энэ тохиолдолд TURN сервер хэрэгтэй
  (`js/network.js` дахь `joinRoom` тохиргоонд `turnConfig` нэмнэ).
- Хуудас нь HTTPS дээр байх ёстой (микрофон ба WebXR-ийн шаардлага) — GitHub Pages үүнийг хангана.
- Локал дээр: `npx serve .` эсвэл VS Code Live Server — `localhost` дээр ажиллана.
